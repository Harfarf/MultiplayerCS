## 🚀 About

**MultiplayerCS** is a multiplayer networking project built with **Unity and C#**, exploring the fundamentals of client-server architecture.

The goal is to understand how multiplayer games establish connections, communicate between clients, and use a central server to coordinate networked experiences.

## 🛠️ Built With

| Technology | Purpose |
|:---:|---|
| 🎮 **Unity** | Game engine and development environment |
| 💜 **C#** | Scripting and application logic |
| 🌐 **Client-Server Architecture** | Multiplayer communication |

## 📦 Getting Started

**1. Clone the repository**

```bash
git clone https://github.com/Harfarf/MultiplayerCS.git
```

**2. Open the project**

- Launch **Unity Hub**.
- Select **Add Project**.
- Choose the cloned `MultiplayerCS` folder.
- Open it with a compatible Unity Editor version.
