## Overview

**MultiplayerCS** is a multiplayer networking project built with **Unity**, exploring the client-server architecture used in multiplayer games.

The project focuses on establishing communication between clients and a central server, providing a foundation for understanding how multiplayer systems work and how they can be implemented in Unity.

## Technologies

- **Unity** — Game engine and development environment.
- **C#** — Scripting and application logic.
- **Client-Server Architecture** — Network communication between clients and a server.

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/Harfarf/MultiplayerCS.git
   ```

2. Open **Unity Hub**.
3. Select **Add Project** and choose the cloned folder.
4. Open the project using a compatible Unity Editor version.

## Project Structure

```text
MultiplayerCS/
├── Assets/           # Game assets and scripts

├── ProjectSettings/  # Project configuration

```

## Purpose

This project serves as a practical exploration of multiplayer game development, with an emphasis on client-server networking and the fundamentals of building networked experiences in Unity.
